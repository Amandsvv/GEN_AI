## Overview
A beginner-focused **Study Tip Generator** built by fine-tuning the final Transformer block of `openai-community/gpt2` on curated `(topic, study tip)` pairs, evaluating honestly against base GPT-2 on unseen topics, and serving predictions through a local Streamlit app.

## Files in This Folder
- `app.py` — Streamlit web application (`Study Tip Generator`) with pointwise documentation and inline comments.
- `Capstone project.pdf` — Complete capstone report covering Stages 1–4, `app.py` (Stage 5), training plots, held-out comparison, and pointwise code explanations.
- `lab_outputs/dataset_split.json` — Saved split of `24` training pairs and `10` held-out topics (zero exact overlap).
- `lab_outputs/training_log.csv` — Epoch-by-epoch mean training loss (`4.5378` at epoch 1 down to `3.4784` at epoch 5).
- `lab_outputs/training_loss.png` — Training loss curve across all 5 epochs.
- `lab_outputs/heldout_outputs.csv` — Base vs. adapted model outputs on the 10 held-out evaluation topics.

## Workflow & Code Summary (Pointwise)
1. **Dataset & Leakage Check:** Splits `24` training `(topic, tip)` pairs and `10` `held_out_topics` with an explicit `assert not overlap` check (`dataset_split.json`).
2. **Model Adaptation:** Freezes all GPT-2 weights except `tuned.transformer.h[-1]`, masks prompt tokens with `-100`, and trains for `5` epochs (`Adam`, `lr=5e-5`, seeded shuffle).
3. **Evaluation & Failure Analysis:** Compares base vs. adapted greedy outputs (`max_new_tokens=45`) on 10 unseen topics (`heldout_outputs.csv`) and documents where generic outputs still require human review.
4. **Streamlit App (`app.py`):**
   - Uses `@st.cache_resource` to load `lab_outputs/study_tip_gpt2/` once in `.eval()` mode.
   - Validates model presence (`config.json`) and non-empty topic input.
   - Runs deterministic generation (`do_sample=False, max_new_tokens=45`) under `torch.inference_mode()` and decodes only newly generated tokens.

## How to Run the Web App
1. Ensure the exported model directory `lab_outputs/study_tip_gpt2/` (generated by the capstone training notebook) is placed inside `lab_outputs/`.
2. Install dependencies (`streamlit`, `torch`, `transformers`) and run:
   ```bash
   streamlit run app.py
   ```
